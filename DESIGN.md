# Arai Hu design system

## Visual world

Archive of a black cloud: a deep midnight field, cobalt cloud masses, bright paper-like text, and electric lime used only as a signal. It is an editorial organization index, not a SaaS landing page.

## Typography

Use the installed Goshtoso system face. Display type is heavy, tight, and oversized; body text stays calm and readable. Project names act as the visual rhythm.

## Composition

The storm field owns the first viewport. Projects appear as an uneven ledger of linked records, never a grid of generic cards. Locale switcher is compact and functional.

## Interaction

One slow cloud drift runs only when motion is allowed. Links invert from pale text to lime signal on hover and retain visible keyboard focus.

## Accessibility

High-contrast text, semantic headings and lists, reduced-motion support, no essential information inside decorative cloud forms.
